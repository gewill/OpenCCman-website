Convert Chinese text on iPhone, iPad or Mac

You do not need a file or a second device. Start with a short paragraph so you can see how the selected preset changes it.

These steps describe the publicly available 2.0 app on iPhone, iPad and Mac. Features still being tested for 2.1 are listed separately in the changelog. Changelog

Convert a short passage

  1. Enter your text. Type or paste into Source. If the workspace contains an example, replace it with your own words.
  2. Choose a conversion preset. Select Simplified Chinese, Traditional · OpenCC, Taiwan · Standard + Idioms, or Hong Kong · Traditional. If you are unsure, read the preset guide first.
  3. Choose Convert. The converted text appears in Result. On iPhone the action sits beside the source area; Mac and iPad can show the two panes side by side or stacked.
  4. Compare before copying. Review names, specialist terms and sentences where more than one Chinese form is possible. Copy or export only the result you want to use.

What the result means

OpenCC converts character forms and dictionary phrases. It does not translate between languages or rewrite a sentence for a different audience. The Simplified preset is not a complete reverse conversion of Taiwan-specific vocabulary. If you change the preset after converting, run Convert again to produce a result using the new choice.

Free use includes 12 conversions from the home workspace each day. A conversion that fails or is canceled does not use an allowance; Pro has no home-workspace limit.

Working with a document? Import one UTF-8 TXT file instead of pasting a long draft. See the TXT guide for the 10 MiB limit and export behavior.
