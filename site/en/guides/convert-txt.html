Convert a UTF-8 TXT file without losing your draft

Use the file workflow for a document you want to keep as a TXT file. The public 2.0 app handles one UTF-8 file at a time, up to 10 MiB.

These steps describe the publicly available 2.0 app on iPhone, iPad and Mac. Features still being tested for 2.1 are listed separately in the changelog. Changelog

Before importing

Save the document as plain-text .txt in UTF-8. A UTF-8 byte-order mark (BOM) is accepted. The app does not guess Big5, GBK or another encoding. If the file exceeds 10 MiB, reduce it or split it before using the public 2.0 workflow.

Import, convert, export

  1. Import one file. Choose Import TXT in the workspace, or drop a single TXT file onto it. A successful import replaces the source text.
  2. Choose a preset and convert. Read the source and result together; a new file is not saved automatically.
  3. Choose Export TXT. The app exports the latest successful result as UTF-8 without a BOM. For example, essay.txt suggests essay-converted.txt; choose the save location in the system panel.

If something goes wrong

An oversized or invalidly encoded import keeps the previous draft. A failed or canceled conversion does not replace the last successful result. The file flow preserves line endings, blank lines, Emoji, combining characters and embedded U+0000; still inspect the converted words before sharing the document.

Large-file Pro conversion is described in the 2.1 candidate notes and is not part of this public 2.0 guide.
